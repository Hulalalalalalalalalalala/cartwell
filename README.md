# Cartwell

商品目录与购物订单。

需要Node.js 24 或更新版本。直接运行 TypeScript，不需要安装其他包。

查看命令帮助：

```sh
node server.ts --help
```

启动本地服务：

```sh
node server.ts serve --host 127.0.0.1 --port 8080 --data-dir data
```

打开 http://127.0.0.1:8080 查看首页。Ctrl+C 停止服务。`--data-dir` 指定本地业务数据目录，重启时继续使用同一目录，商品记录和显示顺序保持一致。

## 首页

- 没有商品时显示空列表提示，有商品时不再显示。
- 点击「新增商品」填写商品名称，再逐行填写规格属性（名称 + 值）、售价和库存。可随时添加或删除规格与属性行。
- 提交成功后返回商品列表，立即看到刚创建的商品及其所有规格。
- 列表中先新增的商品排在前面；每条规格展示属性、两位小数价格和库存。零库存规格标为「缺货」，但仍允许创建和查看。
- 商品名称和属性中的尖括号等字符作为普通文字显示。

## 校验规则

- 商品名称、属性名称和属性值去掉首尾空白后不能为空，保存和展示使用去除空白后的内容。
- 一个商品至少有一条规格，每条规格至少有一个属性。
- 同一规格内不能出现重复属性名称。
- 同一商品内，属性名称和值完全相同的两组规格视为重复，与填写属性的顺序无关，字母大小写仍区分。
- 售价须为十进制金额字符串，允许零和最多两位小数；不接受负数、指数写法、千位分隔符或超过两位的小数，不会四舍五入。
- 库存只能是非负安全整数，不能把小数或空值当作零。
- 任一规格不符合要求时，整个商品都不保存；页面指出具体哪一条规格、哪个字段有问题，保留已填写内容，修正后可再次提交。

## 接口

- `GET /health` 返回服务状态和产品名称。
- `GET /api/products` 返回以 `products` 数组包裹的商品列表。
- `POST /api/products` 新增商品，请求体为商品对象：

  ```json
  {
    "name": "T恤",
    "specs": [
      {
        "attributes": [
          { "name": "颜色", "value": "红色" },
          { "name": "尺码", "value": "M" }
        ],
        "price": "99.50",
        "stock": 10
      }
    ]
  }
  ```

  成功返回 `201` 和包含唯一商品标识的完整商品记录，金额统一为两位小数的字符串。
  请求内容不是合法 JSON 或字段不合规则返回 `400` 及明确原因，不创建部分记录。
  保存失败返回 `500`，不破坏已有商品。

- 未知路径返回 `404`，已知路径不支持的方法返回 `405` 并在 `Allow` 头中列明该路径允许的方法。

```sh
curl http://127.0.0.1:8080/health
curl http://127.0.0.1:8080/api/products
curl -X POST http://127.0.0.1:8080/api/products \
  -H 'content-type: application/json' \
  -d '{"name":"T恤","specs":[{"attributes":[{"name":"颜色","value":"红色"}],"price":"99.50","stock":10}]}'
```
