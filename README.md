# Cartwell

商品目录与购物订单。

需要Node.js 24 或更新版本。直接运行 TypeScript，不需要安装其他包。

查看命令帮助：

```sh
node server.ts --help
```

启动本地服务：

```sh
node server.ts serve --host 127.0.0.1 --port 8080 --data-dir data
```

打开 http://127.0.0.1:8080 查看首页。Ctrl+C 停止服务。`--data-dir` 指定本地业务数据目录，重启时继续使用同一目录。

首页提供「新增商品」表单：填写商品名称后，逐行添加规格，每条规格包含若干属性（名称与值，如颜色/红色、尺码/M）、售价和库存。提交成功后返回商品列表，新创建的商品排在最前；零库存规格标记为「缺货」，但仍可创建和查看。

接口：

- `GET /health` 返回服务状态和产品名称。
- `GET /api/products` 返回商品列表（`products` 数组包裹），首次启动时为空，最新创建的商品排在最前。
- `POST /api/products` 新增商品，成功返回 201 和完整商品记录（含唯一 `id`，金额统一为两位小数字符串）。请求体按实际发送的字节数计算，上限 1,048,576 字节（含 JSON 标点与空白，中文按 UTF-8 字节计）；恰好达到上限仍正常校验，超过上限返回 400 及明确的超限错误说明，商品不保存——预声明 `Content-Length` 与分块传输（chunked）判断一致，且即使内容同时不是合法 JSON 或含无效字段，也只报告超限原因。
- 未知路径返回 404，已知路径不支持的方法返回 405，响应头 `Allow` 列明该路径允许的方法。

新增商品的请求体示例：

```sh
curl -X POST http://127.0.0.1:8080/api/products \
  -H 'content-type: application/json' \
  -d '{
    "name": "基础T恤",
    "specs": [
      {"attributes": [{"name": "颜色", "value": "红色"}, {"name": "尺码", "value": "M"}], "price": "99.00", "stock": 20},
      {"attributes": [{"name": "颜色", "value": "红色"}, {"name": "尺码", "value": "L"}], "price": "99.00", "stock": 0}
    ]
  }'
```

校验规则（网页与接口一致）：

- 商品至少有一条规格；每条规格至少有一个属性。商品名称、属性名称和属性值去掉首尾空白后都不能为空，保存与展示均使用去除空白后的内容。
- 同一规格内属性名称不能重复；同一商品内属性名称和值完全相同的两条规格视为重复（与属性填写顺序无关），不同商品允许重名或使用相同规格。字母大小写敏感。
- 售价必须是十进制金额字符串，允许零和最多两位小数（如 `"0"`、`"10.5"`、`"10.50"`）；不接受负数、指数写法、千位分隔符或超过两位的小数，多余小数不会被四舍五入保存。返回记录中金额统一为两位小数。
- 库存必须是非负安全整数，小数或空值不会被自动当作零。
- 任一字段不合规时整个商品都不保存，返回 400 及具体到规格和字段的原因（`details`）；请求体不是合法 JSON 同样返回 400。保存失败返回 500，不产生部分记录，已有商品不受影响。
- 商品名称和属性中的尖括号等字符在页面上按普通文字显示。

```sh
curl http://127.0.0.1:8080/health
curl http://127.0.0.1:8080/api/products
```

运行回归测试（通过真实接口请求验证新增商品与重复规格判定行为）：

```sh
npm test
```
